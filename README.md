# Timekeeper Daily

> 司辰的时间，不应该浪费在重复点击上。

您是否还在因为《重返未来：1999》漫长的长草期，却每天仍要上线完成重复日活而感到痛苦？

您是否还在为了那点材料，一遍又一遍地点击：

**开始战斗 → 等待 → 再次挑战 → 等待 → 再次挑战……**

您是否曾经看着屏幕上的自动战斗，陷入沉思：

> “既然战斗都是自动的，那为什么点击开始战斗的人不能也是自动的？”

很好。

**Timekeeper Daily** 因此诞生。

这是一个面向《重返未来：1999》的自动化小工具，目标非常朴素：

**把重复的事情，交给电脑自己重复。**

刷材料？让它刷。

清体力？让它清。

领日常？让它领。

你只需要启动程序，然后去做一些真正值得占用你时间的事情。

毕竟，我们玩游戏是为了获得快乐，

**不是为了找个班上。**



## 环境

本地环境：

- Windows 11
- Python 3.10

安装依赖：

```powershell
python -m pip install --upgrade pip
pip install -e .
```

## 运行

```powershell
python main.py
```

## 目标图片

目标图片放在 `targets` 目录中

**记得根据你自己的个人界面更新这里的图片**

当前识别逻辑会直接截取全屏，并按照目标图片的原始尺寸从截图左上角开始滑动匹配。目标图尺寸应尽量来自同一屏幕缩放比例下的截图。

## 功能

- [x] 启动1999客户端
- [x] 成功login
- [ ] 能完美进入homepage（由于login之后进入homepage过程中可能有多种奖励领取界面不好处理，所以这边统一等待用户手动操作结束进入homepage之后，再进行接下来的流程）
- [x] 能退出
- [x] 建立从homepage进入 **入场** 的操作链
- [x] 建立从 **入场** 到 **资源** 的操作链
- [x] 建立从 **资源** 到 **铸币**，**尘埃**，**意志** 的操作链
- [x] 建立完善战斗接口（进入，等待，退出到homepage）
- [x] 建立领取任务奖励接口（日活，周活）
- [x] homepage点角色加好感
- [x] 建立 **点唱机** 奖励领取路径
- [x] 添加 **不休荒原** 操作链
- [x] 制作一个刷材料范本

## 项目结构

```text
TimekeeperDaily/
├── main.py                 # 程序入口
├── config.yaml             # 全局配置
├── setup.py                # 项目与依赖配置
├── core/                   # 自动化核心能力
│   ├── actions.py          # 等待、查找并点击目标等组合操作
│   ├── button_click.py     # 常用界面按钮的点击封装
│   ├── capture.py          # 屏幕与窗口截图
│   ├── click.py            # 屏幕与窗口坐标点击
│   ├── config.py           # YAML 配置加载
│   ├── debug.py            # 图像调试显示
│   ├── launch.py           # 游戏启动与关闭
│   ├── logger.py           # 日志配置
│   ├── matcher.py          # 目标图片加载与匹配
│   └── window.py           # 游戏窗口查找、激活与状态检测
├── farm/                   # 刷材料流程、步骤图片与配置
│   ├── famer.py            # 配置驱动的刷材料脚本
│   ├── famer.yaml          # 刷材料流程配置
│   └── step/               # 刷材料步骤识别图片
├── tasks/                  # 登录、战斗、奖励领取等任务流程
│   ├── goto_fight.py       # 进入资源关卡并开始战斗
│   ├── goto_hoho.py        # 领取点唱机奖励
│   ├── goto_reward.py      # 领取日常与周常任务奖励
│   ├── goto_wilderness.py  # 执行不休荒原流程
│   └── login.py            # 启动游戏并完成登录
└── targets/                # 界面识别所需的目标图片
    └── button/             # 按钮及分页面识别图片
```
